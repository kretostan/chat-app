# Chat App - Developer Guide

## Structure
Monorepo (pnpm workspaces: `frontend/`, `backend/`, `packages/shared/`):
- **frontend** — React 19 + Vite 7 + TanStack Router (generated) + Tailwind CSS 4 + Vitest. Entry: `frontend/src/main.tsx`. Routes in `frontend/src/routes/`.
- **backend** — NestJS 11 on Fastify + Drizzle ORM (SQLite, `backend/src/db/schema/`) + Jest. Entry: `backend/src/main.ts`. Modules: `auth/`, `chat/`, `users/`, `health/`.
- **shared** — Zod schemas shared by frontend + backend. Build output at `dist/`; has a `prepare` script so `pnpm install` auto-builds it.

## Local dev
```
make dev-up        # podman compose up (compose.dev.yaml)
make frontend      # local pnpm dev server (bypasses Docker, fastest iteration)
make backend       # local NestJS watch dev server
make database      # opens Drizzle Studio
```
Frontend proxies API requests to `http://localhost:3001` (backend dev port).
Each service loads `.env.development` from its own directory.

## Run a single package
```
pnpm --filter frontend dev          # Vite dev server :5173
pnpm --filter backend start:dev     # NestJS watch :3001
pnpm --filter shared build          # tsc → dist/
```

## Tests & lint
```
make test-backend                   # Jest unit tests (backend/src/**/*.spec.ts)
make test-backend-e2e               # Jest e2e tests (backend/test/jest-e2e.json)
make test-frontend                  # Vitest run
make test-frontend-watch            # Vitest watch

pnpm --filter frontend biome:lint   # lint both workspaces
pnpm --filter backend biome:lint
```
CI order: `lint → test → build`. Run locally in that order when submitting.

## Migrations & seed
```
pnpm --filter backend db:generate   # create migration from schema changes
pnpm --filter backend db:migrate    # apply pending migrations
pnpm --filter backend db:push       # push schema to DB without migrations
pnpm --filter backend db:seed       # run seed script
```
Schema lives in `backend/src/db/schema/`. Migrations auto-generated by Drizzle Kit.

## Build artifacts
- Backend build output → `backend/dist/` (plain `nest build`, no source maps in prod)
- Frontend build output → `frontend/dist/` (Vite, served by Nginx in prod)
- Shared package output → `packages/shared/dist/` (auto-built on install via `prepare`)

## Docker / CI
Backend and frontend use multi-stage Dockerfiles (`Dockerfile.backend`, `Dockerfile.frontend`) from the repo root. CI push to GHCR as `ghcr.io/kretostan/chat-app/{backend,frontend}:{sha}`. CD pipeline (on `main` pushes) builds `:latest` tags and deploys via SSH + Podman.

## Biome / formatting defaults
- 2-space indent, double quotes, space after colons (root `biome.json`)
- `noExplicitAny` and `useImportType` are **off** — don't reintroduce these
- `useUniqueElementIds` is **off** for frontend JSX
- Assist: `source.organizeImports` is auto-on

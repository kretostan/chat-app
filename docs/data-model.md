# Data Model (SQLite)

## Entities

### users

**Description:** Application users and their credentials.

- `id`: integer (PK, autoincrement)
- `username`: text (unique)
- `email`: text (unique)
- `password_hash`: text
- `avatar_url`: text (nullable)
- `created_at`: text (ISO 8601, default: now)

### chat_rooms

**Description:** Direct messages or group conversations.

- `id`: integer (PK, autoincrement)
- `name`: text (placeholder for DMs, actual name for groups)
- `type`: text ('dm' | 'group')
- `is_private`: boolean (default: true — relevant only for groups)
- `created_at`: text (ISO 8601, default: now)
- `last_message_at`: text (ISO 8601, nullable — set on each new message, used for sorting the chat list)

### chat_room_members

**Description:** Junction table (M:N) connecting users to chat rooms.

- `id`: integer (PK, autoincrement)
- `user_id`: integer (FK → users.id, ON DELETE CASCADE)
- `chat_room_id`: integer (FK → chat_rooms.id, ON DELETE CASCADE)
- `joined_at`: text (ISO 8601, default: now)

**Indexes:**

- Unique index on `(user_id, chat_room_id)` — prevents duplicate membership.

### messages

**Description:** The content of the conversations.

- `id`: integer (PK, autoincrement)
- `content`: text (max 4,000 characters)
- `user_id`: integer (FK → users.id, ON DELETE CASCADE)
- `chat_room_id`: integer (FK → chat_rooms.id, ON DELETE CASCADE)
- `created_at`: text (ISO 8601, default: now)
- `client_message_id`: text (nullable, UUID generated by client for idempotency during WebSocket re-transmission)

**Indexes:**

- Unique index on `(user_id, client_message_id)` — prevents duplicate messages when WebSocket connection drops and the client retries.

---

### sessions

**Description:** Per-device login sessions for token invalidation.

- `id`: integer (PK, autoincrement)
- `user_id`: integer (FK → users.id, ON DELETE CASCADE)
- `is_current`: integer (boolean, default: false, true for the active device session)
- `device_name`: text (nullable, e.g. user-agent for display)
- `created_at`: text (ISO 8601, default: now)
- `last_used_at`: text (ISO 8601, default: now, updated on each request)

---

## Consistency Rules / Notes

- **Access Control:** Every query to `messages` must join with `chat_room_members`
to verify the `request.user_id` belongs to that specific chat room.
- **Pagination:** Uses a `(created_at, id)` keyset as a cursor to ensure stability
when scrolling while new messages arrive.
- **Integrity:** Deleting a user cascades to `chat_room_members` and `messages`.
Deleting a chat room cascades to its members and messages.
- **Idempotency:** The `(user_id, client_message_id)` unique index prevents
duplicate messages when WebSocket re-transmission occurs. Only messages sent
via WebSocket include a `client_message_id`; REST fallback messages skip it
and rely on standard dedup.
